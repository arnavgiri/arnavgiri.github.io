THE DETAILS / 03

Simple to make.
Easy to scan.

QR codes store a link or short message in a matrix of dark and light squares. Your phone's camera can read that information and open the link or show the text.

For reliable results, use dark foreground colors, a light background and leave the quiet zone enabled. SVG is best for scalable print layouts; PNG works well for web and presentations.

GOOD TO KNOW / 04

Frequently asked
questions.

Is this QR code generator free?+

Yes. Generate and download as many QR codes as you need, without an account or subscription.

Is my text or URL uploaded?+

No. QR code generation and file creation happen in your browser. This tool does not send the entered content to a server.

Does the QR code expire?+

No. The code stores the content you entered. If it links to a webpage, that destination must remain online for the link to work.

Which file format should I choose?+

Choose SVG for crisp print graphics at any size, or PNG for a ready-to-use image. Keep sufficient white space around the code.
